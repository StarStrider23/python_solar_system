# Solving the Solar system

The program simulates the Solar system n years from now on, where n > 0 years. It does so by solving a system of appropriate differential equations that contain gravitational interraction between celestial bodies. Moreover, it shows yet another scenario where a Sun-like star appears in the random location between the Earth and the Neptune and wreaks chaos. The program simulates the scenario and how the new star affects all the bodies in the Solar system. By choosing one of the scenarios, the trajectories of the planets and the star(s) are then animated.
