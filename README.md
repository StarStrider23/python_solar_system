# python_solar_system

The program simulates the Solar system 100 years from now on. It does so by solving a system of appropriate differential equations that contain gravitational interraction between celestial bodies. Moreover, it shows yet another scenario where a Sun-like star
appears in the random location between the Earth and the Neptune. The program simulates the scenario and how the new star affects
all the bodies in the Solar system. Both scenarios are then plotted.
